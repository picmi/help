# Searching for people and their application

Use the application filters in **Employment** > **People** to monitor onboarding and follow-up work. They help you find
applications by their current status, when that status was applied, and when the application was last updated.

:::: instructions

## Search for applications in Employment People

1. Go to **Employment** > **People**.
2. Select one or more values in **Status**, such as **Invited**, **In Progress**, **Offered**, or **Accepted**.
3. To find applications by when a status was applied, open **Last Status Changed** and choose a preset or custom date
   range.
4. To find applications by when they were last updated or acted on, use **Last Action Date** separately.
5. Set any other filters you need, then select **Apply** on each filter to update the results.

::: prompt
Some filter headings have a **?** help icon. Hover over it to see a description of what that filter does.
:::
::::

## Application status and date filters

| Filter                  | What it finds                                                                                                                      |
|-------------------------|------------------------------------------------------------------------------------------------------------------------------------|
| **Status**              | Applications with one or more selected statuses.                                                                                   |
| **Last Status Changed** | Applications where the selected status was most recently applied within the chosen date range.                                     |
| **Last Action Date**    | Applications that were last updated or acted on within the chosen date range. This does not necessarily mean their status changed. |

**Last Status Changed** and **Last Action Date** answer different questions:

- **Last Status Changed** — when the selected status was applied.
- **Last Action Date** — when the application was last updated.

For example, to find applications whose status changed some time ago but which have had recent activity, use the older
date range in **Last Status Changed** and a recent date range in **Last Action Date**. When both filters are set, both
conditions apply to the results.

## Last Status Changed date options

Choose one of these presets, or select a custom date range:

- **Last week**
- **Last fortnight**
- **Last month**
- **Last two days**
- **3–5 days ago**
- **6–14 days ago**

**Last two days** includes today and the previous two calendar days, covering three calendar dates.

The date picker offers three boundary controls:

- **Search up to date** — includes dates up to the selected date.
- **Search between two dates** — searches within the selected date range.
- **Search after date** — searches from the selected date onwards.

Turn on **Month only** to switch the date picker to month selection. Day-based presets are disabled while **Month only**
is enabled.

Select **Clear** to remove the current selection. Select **Apply** to apply the selected filter values. **Apply** is
unavailable when there is no selection to apply.

## Example: recently accepted applications

To find applications whose **Accepted** status was applied recently:

1. Select **Accepted** under **Status**.
2. Choose **Last two days** under **Last Status Changed**.
3. Select **Apply** on each filter to apply the selections.

This finds applications where **Accepted** was the most recently applied status within today and the previous two
calendar days. It does not use the date of other application activity as a substitute for the status-change date.

::: prompt
These filters apply to applications in **Employment** > **People**. The status-change date filter is for applications,
not job, employment opportunity, service opportunity, or proposal searches.
:::
