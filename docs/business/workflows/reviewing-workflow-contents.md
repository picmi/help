# Review and export a workflow

Use **Review** mode to inspect the workflow structure and participant-facing content in a searchable table. You can
open a page or workflow item, copy the data, or download it as CSV.

::: prompt
**Review** mode audits workflow contents. It is different from a **Review** outcome in Progressions, which is not
available for
configuration in the current Workflow Builder interface.
:::

## Review workflow contents

::: instructions

1. Go to **Setup** > **Workflows**.
2. Locate the workflow row, click &vellip; (vertical dots) to open the menu.
3. Select **Review** mode.
4. Search the review table to find a page, workflow item, or participant-facing text.
5. Open a page or item from the table to inspect it.
6. Switch between the normal display and **Text only**.
7. Check the workflow contents.

:::

Review can show:

- page and item order
- participant-facing text
- item and question type
- choices
- required or optional state
- visibility conditions
- validation rules
- whether a Library Item is reused in other workflows

## Review issues

Open the **Issues** view to see validation messages. Use the location to open the affected page or workflow item, check
the severity, and follow the suggested resolution. Validate the workflow again after making the change.

## Copy or export review data

::: instructions

1. Open the workflow in **Review** mode.
2. Filter or search the table as needed.
3. Copy the review data to the clipboard, or choose to download it as CSV.
4. Choose **Remove HTML** when you want readable text without formatting markup.

:::

Use **Remove HTML** when the CSV will be reviewed in a spreadsheet or shared with people who only need readable text.
Keep HTML when you need to inspect formatting or links stored in the description.

## Example

Before reviewing a seasonal employment workflow, search for **passport**, switch to **Text only**, and confirm the
question type, choices, required state, visibility conditions, and validation rules. Download the result as CSV with
**Remove HTML** enabled when sharing it with a manager.
